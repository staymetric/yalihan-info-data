# Yalihan Info Data

Public weekly programme data for Yalihan Info Page.

Files:
- data/aspendos-weekly-program.json
- data/una-weekly-program.json

Routine update:
1. Edit the correct hotel JSON on main.
2. Keep all seven day keys and valid JSON.
3. Commit the change.
4. Open the matching Today page and verify the update.

The Info Page reads this repository first and falls back to the packaged local weekly-program.json if the remote file is unavailable or invalid.
